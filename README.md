# Luma Kids website prototype

This workspace was empty when the update began. The available neighboring project was a static HTML/CSS/JavaScript prototype, so this workspace contains that prototype with revised Russian business copy and its existing selectable catalog and local inquiry draft form.

Open `index.html` in a browser. `catalog.html` contains the product photo selection. Edit the business copy in those HTML files and the provisional model entries in `js/app.js`.

## Content notes

- Product photos are a preliminary selection. Model names, sizes, materials, availability, and per-model age ranges still need company confirmation.
- The reported minimum order value and payment split are presented as estimates / manager-provided terms. Confirm them before publication.
- Factory capacity, partner names, certifications, testimonials, address, and direct contact details are not published because they require confirmation or permission.
- The form only generates a copyable draft in the browser. It does not send Telegram notifications or connect to a CRM.
- The available source is not a Next.js App Router project. This prototype also does not yet implement English and Uzbek versions or language switching.
